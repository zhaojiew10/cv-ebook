# 精通计算机视觉：从像素到生成式视觉

一本系统介绍计算机视觉的中文电子书。全书以理论解释、数学关系、架构对比和实践流程为主线，将相关内容按知识逻辑整理为 **6 个部分、35 章**，并配有 **39 幅课程原帧与 SVG 图例**。

内容从数字图像与卷积基础出发，逐步深入经典 CNN、目标检测、图像分割、生成模型、Vision Transformer 与大规模视觉检索。

## 本书内容

### 第一部分 · 图像处理与计算机视觉基础（第 1—4 章）

语义鸿沟、经典与现代视觉流程、HOG/SIFT 与传统分类器、像素与矩阵、RGB/HSV/灰度、位深、几何与光度变换、卷积滤波和人脸识别预处理。

### 第二部分 · 深度学习与 CNN（第 5—9 章）

感知机与深度网络、激活函数、交叉熵、反向传播、学习率与优化器、卷积、ReLU、池化、完整 CNN，以及 PyTorch 数据管道、训练循环和模型评估。

### 第三部分 · 高级 CNN 与模型优化（第 10—15 章）

LeNet、AlexNet、VGG、ResNet、Inception、DenseNet、EfficientNet、骨干网络选择、迁移学习、特征提取、微调、分层学习率、EWC、训练诊断、数据增强和正则化。

### 第四部分 · 目标检测（第 16—20 章）

检测输出、IoU、精确率—召回率、mAP、NMS、R-CNN 系列、YOLO、SSD、DETR、Transformer 编解码器和匈牙利二分匹配。

### 第五部分 · 图像分割（第 21—25 章）

语义与实例分割、像素级损失、FCN、编码器—解码器、U-Net、Mask R-CNN、ROI Align、多任务学习、SAM、SAM2 和 SAM3。

### 第六部分 · 生成模型、ViT 与视觉检索（第 26—35 章）

AE、VAE、重参数化、GAN、DCGAN、WGAN、StyleGAN、CycleGAN、ViT、自注意力、位置编码、DeiT、Swin、视觉嵌入、SimCLR、Triplet Loss、FAISS、IVF、PQ、HNSW、ArcFace 和 CLIP。

## 推荐阅读方式

- **系统学习**：按第 1—35 章顺序阅读，建立完整知识路径。
- **视觉工程主线**：先读第 1—9 章，再读第 16—25 章。
- **生成模型与 ViT 主线**：复习第 5—8 章后，阅读第 26—32 章。
- **视觉检索主线**：掌握 CNN 基础后，阅读第 33—35 章。
- **复习与查阅**：通过[完整目录](docs/index.md)定位架构和术语，结合各章小结回顾核心机制。

## 内容说明

本书依据《Mastering Computer Vision: From Pixel to Detection to Gen-CV》的课程内容整理，不按视频逐课摘要，也不采用问答形式。代码讲解已融入对应章节，以操作流程、关键 API、公式和必要片段呈现。

本书不附原视频和数据集。各章末尾设有小结，章节之间提供上一章、下一章及返回目录的导航链接。
