# 第 26 章 自编码器与潜在空间

分类、检测和分割都在理解已经存在的图像，生成式视觉则进一步学习图像数据的组织方式，使模型能够重建样本、修复输入，甚至合成训练中未曾出现的新图像。自编码器（Autoencoder，AE）是理解这一转变的起点：它用编码器把高维像素压缩为潜在表示，再用解码器恢复图像。真正决定模型能力的，不只是“压缩后再还原”的外形，而是瓶颈处的潜在空间是否具有合适结构。本章从环境空间、流形与潜在空间的关系出发，说明 AE 的架构、重建目标、适用边界及基本实现流程，并为变分自编码器的概率建模建立参照。

## 从像素空间到潜在空间

### 环境空间与图像流形

一幅高为 $H$、宽为 $W$、通道数为 $C$ 的图像，可以表示为 $\mathbb{R}^{H\times W\times C}$ 中的一个点。这个容纳所有像素组合的高维环境空间（ambient space）极其庞大，其中绝大多数组合只是随机噪声，具有物体结构、纹理和语义的自然图像只占很小部分。随机给每个像素赋值，几乎不可能直接得到一张有意义的狗、汽车或人脸图像。

自然图像并非均匀散布在整个环境空间中，而是集中在一个低维得多的流形（manifold）附近。流形可以理解为高维空间中的有序区域：相邻位置对应相互关联的图像变化，例如人脸姿态、光照、年龄、微笑程度、发色和纹理的改变。它保留了图像之所以成为图像的约束，把少量有效信号从海量的无意义像素组合中区分出来。

### 潜在表示的作用

潜在空间（latent space）是对这种有序结构的低维编码。编码器不再要求逐个保存全部像素，而是用 $d$ 维向量 $z$ 表示影响图像变化的主要因素，其中通常有 $d\ll HWC$。课程以人脸为例，用约 128 维潜在向量说明少量因素即可概括大量像素变化；这个数值用于解释降维思想，并不意味着所有数据集都应固定采用同一维度。

三个概念形成了生成模型的基本地图：环境空间提供所有可能的像素组合，图像流形限定有意义的自然图像区域，潜在空间则用紧凑坐标组织流形上的变化。理想的潜在表示应让相似概念彼此接近，使沿某些方向移动对应可理解的属性变化。生成模型因此在低维空间中选择或变换 $z$，再由解码器映射回图像，而不是在原始像素空间盲目随机搜索。

## 自编码器的编码—解码架构

自编码器由编码器 $E_\phi$、瓶颈潜在表示和解码器 $D_\theta$ 组成，其确定性映射为

$$
z=E_\phi(x),\qquad \hat{x}=D_\theta(z).
$$

输入图像 $x$ 经卷积块逐步下采样，空间尺寸缩小，而特征通道通常增加，最终在瓶颈处形成紧凑的 $z$。瓶颈限制了可供模型使用的信息容量，迫使网络优先保留轮廓、结构、光照和纹理等对重建有用的模式，而不是无约束地复制输入。这里的“压缩”不是简单删除像素，而是学习一种能够支持还原的抽象表示。课程以空间尺度缩至输入的 $1/16$ 或 $1/32$ 说明下采样过程，实际比例由卷积层数与步幅共同决定；判断瓶颈是否合适，要看它能否在容量受限时仍保留重建所需信息。

解码器执行相反方向的映射。全连接层可先把潜在向量整理为三维特征图，随后通过转置卷积逐步扩大空间尺寸、减少通道数，直到恢复输入图像的高度、宽度和通道数。课程展示的一种通道收缩次序是由 512 逐步降至 256、128、64，最后得到 3 通道输出；它说明的是解码器的设计方向，而非所有实现必须照搬的层数配置。转置卷积在这里承担可学习上采样，不是把低分辨率图像机械放大，而是依据训练中学到的图像规律重新生成像素。

完整训练闭环为：编码输入批次，取得潜在编码，解码得到 $\hat{x}$，比较 $x$ 与 $\hat{x}$，再将误差反向传播到编码器和解码器的全部可训练参数。推理时，编码器和解码器也可分别使用：前者提供紧凑表示，后者把潜在编码转换为图像。

## 逐像素重建目标

AE 的直接目标是让输出尽可能接近输入。对包含 $N$ 个像素标量的图像，均方误差（MSE）写为

$$
\mathcal{L}_{\mathrm{AE}}
=\frac{1}{N}\sum_{i=1}^{N}(x_i-\hat{x}_i)^2.
$$

实际批量训练通常在批次及图像全部元素上求均值。每个位置的误差先作差再平方，因此正负偏差不会相互抵消，较大的偏差会受到更重惩罚。平方函数可微且梯度平滑，适合通过反向传播联合更新网络。损失的理想下限为 0，此时所有对应像素完全一致。

MSE 衡量的是逐位置数值一致性，并不直接等同于人类感知的语义质量。它与 AE 的重建任务高度匹配：输入本身就是目标，模型不需要额外类别标签。若目标是去噪，训练则应使用带噪输入与干净目标之间的对应关系，使瓶颈偏向保留稳定结构而非噪声；若只是普通重建，则输入与目标均为原图。二者共享架构，但训练样本的构造不同。

## 确定性潜在空间的能力边界

普通 AE 对每个训练样本产生一个确定编码。相同输入在参数固定时映射到相同位置，训练目标又只要求这些位置能够被解码，并没有额外约束编码点之间的空隙。因此，训练样本附近可以形成有效的局部表示，未覆盖区域却没有可靠的语义保证。在两个有效编码之间随意选点，解码器可能输出模糊团块或无意义图案。

这解释了“会重建”不等于“会生成”。重建时，$z$ 来自真实输入的编码，解码器处理的是训练目标覆盖过的表示；随机生成时，$z$ 来自人为指定或随机采样，可能落在潜在空间的空洞中。平滑插值同样要求中间区域具有连续语义，而单纯最小化重建误差并未提供这一保证。

| 对比维度 | 普通自编码器 AE | 变分自编码器 VAE |
|---|---|---|
| 编码方式 | 输入到单一潜在点的确定性映射 | 输入到潜在分布参数的概率映射 |
| 空间约束 | 主要受重建损失驱动，点间区域可能不规则 | 通过分布约束增强连续性与可采样性 |
| 典型优势 | 重建、压缩、修复与去噪 | 随机生成、属性变化和潜在插值 |
| 重建倾向 | 更强调忠实保留输入 | 为分布规则化和变化能力付出一定重建精度 |
| 随机取点解码 | 容易落入无意义区域 | 更适合从规定先验中采样 |

因此，AE 并非“失败的生成器”，而是目标不同的表示学习模型。需要紧凑保存和忠实恢复时，它的确定性反而有利；需要主动探索新样本时，则必须进一步处理潜在分布，而不能只更换解码器。

## MNIST 简化实现与评估流程

课程用 MNIST 展示最小可行流程。环境包括 NumPy、Matplotlib、PIL、PyTorch 与 TorchVision；数据为 $1\times28\times28$ 的灰度数字图像，演示划分出 10000 个训练样本和 2000 个测试样本。为了突出编码与解码原理，示例没有用卷积块，而以 `nn.Sequential` 和全连接层搭建 vanilla AE：编码器逐步压缩到瓶颈，解码器再扩展到 $28\times28$ 的输出。

其训练与评估可概括为以下伪代码：

```text
准备训练集、测试集与 DataLoader
构建 encoder、decoder，并定义 MSE 与优化器
重复 5 个 epoch：
    遍历训练批次
    z = encoder(x)
    x_hat = decoder(z)
    loss = MSE(x_hat, x)
    清空梯度，反向传播，更新参数
切换 eval 模式，在测试图像上重建
比较原图与重建图，并检查训练损失曲线
```

演示经过 5 个 epoch 后，训练损失由约 0.09 降至 0.032，曲线仍在下降，说明该运行尚有继续训练的空间。测试集只用于训练后的评估，不能参与参数更新。重建结果虽不完美，但仍能保留数字结构；这与理论预期一致：简化 AE 可以学习输入压缩与恢复，却不能据此推断它已具备可靠的随机生成能力。若要扩展到更复杂的自然图像，可把全连接编码器、解码器替换为卷积与转置卷积块，同时保持“编码—瓶颈—解码—重建损失”的闭环不变。

## 本章小结

- 自然图像位于高维环境空间中的低维流形附近，潜在空间用紧凑坐标组织其主要变化因素。
- AE 通过编码器、瓶颈和解码器学习 $x\rightarrow z\rightarrow\hat{x}$，以逐像素 MSE 驱动端到端重建。
- 确定性编码并未约束潜在点之间的空隙，因此良好的重建能力不能自动转化为随机生成和平滑插值能力。
- AE 更适合压缩、修复和去噪；VAE 通过概率分布及规则化改善潜在空间的可采样性。
- MNIST 示例展示了数据划分、模型训练、损失观察和测试集重建的完整流程，其全连接结构可替换为卷积架构。
